Something doesn't get the values I expect at startup, tried debugging line by line using the editor, which was very helpful since I understood the order stuff happens in the script, but I didn't figure out the problem yet. At least now I know that while you define a variable in gd-script, the first thing is initializing all the variables you declared but not with the values you declared for them, for exampe:
  - the first pass just declares them as their default 0, false or empty strings, basically assigning a type to them
  - then on the second pass they get the values you assigned to them in the script, without running a set function even if they have
  - if they are exported and have different values in the inspector, then there will be a third pass which will run their set functions too
